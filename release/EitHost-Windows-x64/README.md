# EitHost Windows x64

解压整个文件夹到一个可写的固定位置，然后双击 **EitHost.App.exe**。不要在压缩包内直接运行，也不要只复制 EXE。程序已包含 .NET 运行时，无需安装开发工具或 .NET SDK。

支持 .NET 10 的 Windows x64 系统。建议使用仍受支持的 Windows 11；Windows 10 请确认具体版本仍受 .NET 10 支持。

第一次使用：

1. 确认已安装 USB2070 驱动，再连接采集卡和 DDS 串口设备。
2. 在程序中扫描设备并完成配对。
3. 实时重构使用接收方已安装的兼容 PyEIDORS 后端。在程序中选择本机后端目录和配置。

启动测量前，请等待后端验证完成，并确认后端路线已选定。若提示后端尚未配置、正在验证或验证失败，请按提示完成本机路径和路线设置后重新点击启动；软件会在操作硬件及创建实验记录前检查这些条件。

复现 2026-09-06 本套植物的稳定性实测时，在“设备设置”中使用：3125 Hz、名义电流 10 µA、PGA 1、每通道 20 周期、前丢弃 8 周期、后丢弃 4 周期、扫描圈数 0（连续），采样率 200000 Hz、量程 ±5 V，每块 3 帧且最少 3 帧有效。本组参数针对当前植物与电极；程序的通用默认值仍为 30 µA、前/后丢弃 3/2，启动前需按本组实测配置设置。

双套同频分时伪三维（2.0.12 的 10 kHz 三帧方案）：

1. 绑定两套独立设备，USB2070 设备号和 DDS 串口均须不同。单套时“伪三维”开关不可用。
2. 停止现有采集，勾选“伪三维”，展开“伪三维参数”选择下层、上层；两层采用下层的网格与逆问题设置。
3. 点击“启动本套”或“全部启动”，都会启动所选双套分时组。模式固定为：10000 Hz（相同 FTW=5592）、10 µA、PGA 1、相邻 16 电极、20 周期、前 8 后 4、ADC 200000 Hz / ±5 V、每层每轮一个三帧块。单套二维保存的参数不会被覆盖，也不会覆盖本模式的固定采集参数。
4. 每个时隙先启动 ADC，再让 DDS 仅扫描 3 圈；利用本槽的静默前段与启动时间范围定位完整三帧，不额外激励启动帧或定位帧。上一套精确完成并确认停扫、关闭 DAC、进入 Idle，且已确认关闭输出满 20 ms 后，才可启动下一套；停止确认命令本身的耗时计入这一间隔。两套固件都须为支持 ScanStatus 的 v1.4 或更新版本；不兼容会拒绝启动，不自动刷固件。
5. 为两层锁定有效参考后观察伪三维；可使用现有同步参考功能。只组合相同会话、相同轮次的两层，检查规范网格元数据以及实际节点坐标、连接与参数索引顺序完全相同。时间差连同主机计时不确定度最多 1500 ms。任何条件不满足时显示原因，不借用另一轮旧帧。
6. 停止任一套、关闭伪三维或解绑成员都会停止整个组。运行中不能换层设备。“完整记录”保存完整原始波形、有限扫描边界与定位参数、采样时间／轮次，以及两层关联的伪三维 HDF5；离线按同一有限扫描算法补算，也支持一槽跨 HDF5 分片。“仅预览”保持不自动入库。旧 2.0.11 方案的归档仍可读取，实时运行只接受当前方案。

按 10 kHz 计算，每帧 32 ms、每套三帧 96 ms，两套有效扫描共约 192 ms。调度目标为每秒 3 轮，初始化、通信、质量重定位、磁盘及逆问题处理会影响实际速度。它生成两层二维场之间的伪三维插值，保留分时的层间时间差，不等同于同时采样或真实三维反演。未检出可信变化时，本轮使用标记清楚的零差中性层，原始电压继续保留；未通过采集质量检查的数据不会生成有效图层。

2026-09-06 双套实采中，多数轮次约 335 ms；COM7／USB #0 的 20 轮全部得到合格三帧，COM5／USB #1 的 20 轮均因电极拓扑问题不合格，故尚未通过双层成像或持续每秒 3 幅有效图的验收。此配对只代表本次接线识别结果，重新插拔后应重新确认。

PyEIDORS 安装器提供的稳定入口是 `/home/<实际 WSL 用户名>/apps/PyEIDORS`。请在目录选择器中选择对应的 `\\wsl.localhost\<实际 WSL 发行版>\home\<实际 WSL 用户名>\apps\PyEIDORS`；尖括号中的内容必须替换为接收方电脑的实际值。程序会保留用户选择的发行版名称和目录，并通过稳定入口下的 `current` 链接跟随已安装版本，因此无需进入 `versions/<版本号>` 子目录。

`eithost.reconstruction.example.json` 是配置示例。程序默认读取 `%LOCALAPPDATA%\EitHost\eithost.reconstruction.json`；也可用 `EITHOST_RECONSTRUCTION_CONFIG` 指定配置文件。已有配置可继续使用。示例中的用户名、WSL 发行版和路径需要按本机环境修改。

程序首次运行时在 EXE 所在文件夹创建自己的 `Data`，存放实验数据与数据库。本包不含发送方的实验数据、设备配对记录或个人配置。请固定使用这个目录，备份时完整保留 `Data`。

升级现有安装时，先把新包解压到与旧安装不同的临时目录并关闭软件，再在 PowerShell 中运行：

```powershell
.\scripts\update-eithost-install.ps1 -PackageDirectory . -InstallRoot "C:\EitHost\EitHost-Windows-x64"
```

把 `InstallRoot` 改成旧安装目录。脚本先校验包内全部 SHA-256，再以目录事务替换程序文件并迁移原 `Data`；失败时保留旧程序，旧版本遗留 DLL 不会混入新版本。不要手工逐文件覆盖升级。

包内含采集、设备管理、数据存储、解调、质量诊断、回放、ROI、二维及伪三维显示和重构集成层。USB2070 内核驱动、WSL2 与 PyEIDORS 后端需要在接收方电脑上已有；它们不随本包重复发送。实验室当前使用的 PyEIDORS v2 尚未公开，请使用已经获得并配置好的兼容版本。

`scripts` 下包含安全升级脚本和厂商驱动辅助脚本。驱动请优先使用厂商安装程序；驱动辅助脚本中的开发仓库诊断步骤需要开发环境，不用于免开发环境的安装。

`VERSION.json` 记录版本及构建来源，`SHA256SUMS.txt` 记录运行文件校验值。文件缺失或启动提示 HDF5 运行库不可用时，请重新完整解压。
